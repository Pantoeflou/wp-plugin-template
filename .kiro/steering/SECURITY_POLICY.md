# Security Policy

This plugin follows strict WordPress security practices.

---

# Core Rules

- All state-changing actions require nonces.
- All admin actions require capabilities.
- All input sanitized.
- All output escaped.
- All SQL prepared.
- REST routes must define permission_callback.
- No secrets stored in repository.

---

# Responsible Disclosure

Security vulnerabilities should be reported privately before public disclosure.

---

Security is not optional.
